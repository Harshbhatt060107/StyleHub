# 👕 StyleHub - Fashion & Apparel Website

## 📌 Project Overview

StyleHub is a responsive Fashion & Apparel website developed using HTML, CSS, and JavaScript. Users can browse premium fashion products, search and filter collections, view detailed product information, add items to the shopping cart, proceed to checkout, and manage a demo account.

This project was developed for educational and internship purposes.

---

## 🚀 Features

- Responsive Home Page
- Product Listing Page
- Product Details Page
- Search Products
- Category Filter
- Shopping Cart
- Add to Cart
- Remove Items from Cart
- Clear Shopping Cart
- Checkout Page
- Demo Login System
- My Account Page
- About Us Page
- Contact Us Page
- Newsletter Section
- Mobile Friendly Design
- GitHub Pages Deployment
- Cross-Browser Tested
